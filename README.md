Kova Code Studio
Молниеносная нативная среда разработки (IDE), созданная на чистом C++ (Win32 API) и движке Scintilla.
Оптимизирована для профессионального скриптинга SourcePawn (CS:S v34), разработки на Python и верстки Web-проектов.

Ключевые возможности

Абсолютная производительность: Никаких Electron, C# или Java. Программа написана на нативном C++ и работает со скоростью света.

Интегрированная сборка (Smart Run - F5):

Автоматическая компиляция .sp скриптов с созданием .smx рядом с исходником.

Двойной клик по ошибке в консоли мгновенно переносит к строке с багом.

Поддержка запуска .py и предпросмотра .html.

Собственный парсер синтаксиса: Полная поддержка палитры VS Code Dark+ и Code Folding (сворачивание функций).

Продвинутый интерфейс:

Нативный движок вкладок (без белых полос Windows) с контекстным меню.

Индикаторы изменения строк (Git-маркеры).

Встроенная палитра цветов MoreColors для SourceMod (Ctrl+M).

Сохранение сессии и авто-подгрузка библиотек.

Сборка из исходников

Для самостоятельной компиляции Kova Code Studio вам потребуется:

Microsoft Visual Studio 2026 (C++ Desktop Development).

Выбрать конфигурацию Release и x64.

Убедиться, что в папке проекта лежит файл logo.ico, а в Файлах ресурсов добавлен icon.rc.

Нажать Ctrl + Shift + B (Сборка решения).

Важно: Для работы скомпилированного .exe файла необходимо, чтобы рядом находилась библиотека Scintilla.dll (или SciLexer.dll). Программа умеет автоматически искать ее в соседних папках.
